# Projets

Ce dossier regroupe les principaux projets et services sur lesquels j’ai travaillé pendant mon alternance.

Chaque sous-dossier correspond à une solution, un service ou un sujet technique documenté de manière indépendante, avec l’objectif de présenter à la fois le contexte du projet, les choix techniques réalisés et une documentation réutilisable dans d’autres environnements.

## Objectif du dossier

Ce dossier a pour but de rassembler des projets menés dans un cadre professionnel, puis réécrits dans une logique de documentation technique claire, structurée et transposable.

L’objectif n’est pas uniquement de montrer ce qui a été réalisé pendant l’alternance, mais aussi de proposer des contenus pouvant servir de base de travail, de test ou d’inspiration dans d’autres contextes.

## Contenu des projets

Selon les cas, chaque dossier projet peut contenir :

- un README de présentation ;
- le contexte ayant motivé la mise en place de la solution ;
- une documentation d’installation ou de configuration ;
- des scripts d’automatisation ;
- des captures d’écran ou schémas ;
- des notes sur les limites, tests ou adaptations possibles ;
- des indications sur les différences entre environnement de test et mise en production.

## Logique de documentation

Les projets présentés ici ont été réalisés dans le cadre de mon alternance chez Konexio, mais la documentation a vocation à rester aussi réutilisable que possible.

Le contexte d’origine peut être rappelé dans chaque README afin d’expliquer le besoin initial, tandis que la partie technique est rédigée pour pouvoir être comprise, adaptée et réemployée dans d’autres environnements.

## Exemples de projets

Parmi les sujets abordés dans ce dossier :

- Vaultwarden ;
- GLPI ;
- Moodle ;
- Centreon ;
- observabilité et supervision ;
- automatisation via scripts Bash.

## Organisation

Chaque sous-dossier est consacré à un projet précis.

L’idée est de séparer clairement les sujets liés aux services et aux solutions déployées des éléments plus transverses liés à la construction de l’environnement technique, qui sont présentés dans le dossier `infrastructure/`.
